# MTH 3300 – Algorithms, Computers, and Programming I

This repository contains my coursework, programming exercises, and projects from **MTH 3300: Algorithms, Computers, and Programming I** at **Baruch College**.

## About the Course

MTH 3300 introduced me to programming and algorithmic problem-solving using **Python**. Throughout the course, I learned how to break problems into smaller steps, develop algorithms, and translate those algorithms into working programs.

The course covered both fundamental and more advanced Python concepts, including:

* Variables, expressions, and data types
* Conditional statements (`if`, `elif`, and `else`)
* `for` and `while` loops
* Functions and reusable code
* Lists, dictionaries, and other data structures
* File handling
* Algorithm development and problem-solving
* Object-Oriented Programming (OOP)
* Classes, objects, methods, and attributes
* Data analysis and manipulation using **Pandas**
* Working with datasets and DataFrames
* Structured program development

## About This Repository

I created this repository to organize and showcase the work I completed throughout MTH 3300. It includes programming assignments, practice problems, and projects that demonstrate my progression from basic Python programming to working with object-oriented programming and data analysis tools such as Pandas.

This course helped build my foundation in programming and algorithmic thinking and prepared me for more advanced coursework in computer science.
